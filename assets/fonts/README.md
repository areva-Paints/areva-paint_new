# Warranty report fonts

Unmodified Noto fonts from the Debian fonts-noto-core distribution, licensed under SIL Open Font License 1.1 (see LICENSE.Noto.txt). Bundled privately for server-side PDF generation so Render/GoDaddy do not need system fonts or a browser installed. Includes Latin/currency, Devanagari, Kannada, Tamil, Telugu and symbol fallback coverage. Fonts are subset into individual PDFs. Uncovered characters are written as explicit Unicode code-point markers rather than silently dropped.
