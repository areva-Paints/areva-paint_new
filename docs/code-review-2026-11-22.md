## Operating limits retained

Use one Node process/instance with a private persistent disk. JSON read/modify/write, sessions and rate limits are not shared across instances. Restricted permissions, exclusive writes and atomic JSON replacement do not replace consistent backups or database transactions. Back up the entire data directory, including public uploads, receipts, building photos and history-access metadata.

Real WhatsApp/SMS OTP and customer PDF delivery remain separate integrations. Demo entry does not verify phone ownership, and history still requires complete references plus the matching primary/login number. Final admin decisions remain immutable. Signature checks are not antivirus scanning or proof of document authenticity. Sample-order/loyalty/payment demonstrations were not turned into real integrations by this review.

Larger admin/warranty modules and preserved-template adapters remain candidates for gradual extraction. This refactor concentrates shared rules and verified fault boundaries while preserving the existing workflows and data format.
